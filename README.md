Stock Portfolio Investment Calculator

This is a simple Python based stock portfolio calculator. It allows users to build a basic stock investment portfolio, calculate total investment value, and optionally save the portfolio details to a file.

Features

Displays a predefined list of available stocks with fixed prices

Allows users to buy multiple stocks and quantities

Keeps track of the current portfolio

Calculates total investment value in real time

Option to save the portfolio summary to a text file

Displays a final investment breakdown

Available Stocks

The program currently supports the following stocks:

AAPL

TSLA

MSFT

AMZN

GOOG

Each stock has a fixed price defined inside the program.

How the Program Works

The program starts by showing the available stock symbols.

The user enters a stock symbol they want to invest in.

The user enters the number of shares for that stock.

The portfolio updates and shows the total investment value.

The user can continue adding stocks or type done to finish.

After finishing, the user can choose to save the portfolio to a .txt file.

The final portfolio summary is displayed on the screen.

How to Run the Project

Make sure Python is installed on your system.

Clone the repository or download the files.

Open a terminal in the project folder.

Run the program using:

python stock.py

Output Example

Displays each stock with number of shares

Shows price per share

Calculates total investment value

Optionally saves data in a text file
